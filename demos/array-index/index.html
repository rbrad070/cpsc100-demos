Array Index Explorer: No Bounds Checking

Pick an index and read or write marks[i]. C turns the index into a memory address and goes there, whether or not that address belongs to the array.

Memory

int count = 3;
int marks[5] = {85, 92, 64, 70, 77};
int total = 388; // one possible layout

Addresses are simplified. Each int takes 4 bytes. Where other variables end up is up to the compiler, so the neighbours here are just one possibility.
